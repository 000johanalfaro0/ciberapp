# Scripting en Python: deja de ser script kiddie

Copiar y ejecutar herramientas ajenas no te hace hacker. Te hace **script kiddie**: alguien que usa software creado por otros sin entender qué hace por debajo. El problema no es de ego. Es práctico: las herramientas prefabricadas son fáciles de detectar por antivirus y sistemas de monitoreo, y fallan en el momento en que necesitas adaptarlas.

Escribir tus propios scripts cambia las reglas del juego. Y el lenguaje que más usan los hackers para eso es Python.

## Por qué Python, y no otro

sqlmap, scapy, SET, w3af. Herramientas que aparecen una y otra vez en auditorías de seguridad reales. Todas están escritas en Python.

La razón son los <a class="term" href="/glosario#MODULO">módulos</a>. Un módulo es un bloque de código preescrito, guardado en su propio archivo, que importas y reutilizas sin escribirlo de nuevo. Python trae más de 1.000 módulos de serie: manejo de archivos, criptografía, protocolos de red, tipos de datos. Miles más viven en repositorios externos. Es la diferencia entre tener un martillo y tener un taller entero.

Bash, Perl y Ruby también sirven para construir herramientas. Pero los módulos de Python hacen el trabajo mucho más rápido.

## De dónde salen los módulos: pip y PyPI

**pip** (Pip Installs Packages) es el gestor de paquetes de Python. Descarga e instala módulos desde **PyPI** (Python Package Index), el repositorio oficial donde la comunidad publica sus paquetes. En Kali ya viene incluido; si necesitas instalarlo:

```bash
apt-get install python3-pip
```

Para instalar un módulo desde PyPI:

```bash
pip3 install <nombre-del-paquete>
```

Los paquetes se guardan automáticamente en `/usr/local/lib/<versión>/dist-packages`. Si no sabes dónde quedó uno, pregúntale a pip:

```bash
pip3 show pysnmp
```

Eso devuelve nombre, versión, autor, licencia y ruta del paquete. También puedes instalar un módulo a mano: lo descargas con `wget`, lo descomprimes con `tar -xzf` y ejecutas `python3 setup.py install`. Más trabajo, pero útil cuando el módulo no está en PyPI.

## Variables: donde guardas tus datos

Una <a class="term" href="/glosario#VARIABLE">variable</a> es un nombre que apunta a un valor almacenado en memoria. Le das un nombre, le asignas un valor, y cada vez que uses ese nombre el programa recupera el valor asociado. En Python no necesitas declararla antes; la creas en el momento de asignarle algo.

```python
#!/usr/bin/python3
name = "OccupyTheWeb"
print("Greetings to " + name + " from Hackers-Arise")
```

La primera línea le dice al sistema que use el intérprete de Python 3. La segunda define una variable de tipo **string** (texto entre comillas). La tercera usa `print()`, que muestra en pantalla lo que le pases entre paréntesis.

Python maneja varios tipos de datos:

- **String**: texto. Los números dentro de un string se comportan como texto; no puedes operar con ellos matemáticamente.
- **Integer**: número entero sin decimales. Operable.
- **Float**: número con decimales, como `3.1415`.
- **List**: secuencia de valores guardados juntos, como `[1, 2, 3, 4, 5]`.
- **Dictionary**: conjunto sin orden donde cada valor tiene una clave única, como `{'manzana': 'roja', 'uva': 'verde'}`. Para leer la uva: `print(frutas['uva'])`. Para cambiar la manzana: `frutas['manzana'] = 'verde'`.

## Cómo ejecutar tu script

Antes de correrlo, necesitas permiso de ejecución. Ya conoces `chmod` del módulo de permisos:

```bash
chmod 755 hackers-arise_greetings.py
./hackers-arise_greetings.py
```

El `./` al inicio le dice al sistema que busque el script en el directorio actual, porque por seguridad tu directorio actual no está en `$PATH`.

Para escribir scripts puedes usar cualquier editor de texto plano. Si quieres algo más potente, existen los **IDE** (entornos de desarrollo integrados): editores con resaltado de sintaxis, depuración y autocompletado. Kali incluye PyCrust, y PyCharm (de JetBrains, con edición gratuita) es una de las mejores opciones para seguir aprendiendo.

## Comentarios y formato: dos cosas que no son decorativas

Los **comentarios** son texto que el intérprete ignora. Explican qué hace tu código para tu yo del futuro o para otros programadores. Una línea se comenta con `#`. Para varias líneas, usa tres comillas dobles `"""` al inicio y al final del bloque.

El **formato** sí importa en Python, y mucho. La indentación —los espacios al inicio de cada línea— define qué líneas pertenecen a un mismo bloque de código. Si indentas dos niveles, debes mantener eso consistente en todo el bloque. En otros lenguajes la indentación es buena práctica; en Python es obligatoria, porque el intérprete la usa para agrupar el código.

## Funciones: acciones reutilizables

Una <a class="term" href="/glosario#FUNCION">función</a> es un bloque de código que ejecuta una acción específica. `print()` es una función. Python trae miles integradas:

- `exit()` cierra el programa.
- `len()` cuenta los elementos de una lista o diccionario.
- `int()` convierte un valor a entero.
- `float()` convierte un valor a decimal.
- `type()` te dice el tipo de un dato.
- `sorted()` ordena una lista.
- `range()` genera una secuencia de enteros entre dos valores.
- `max()` devuelve el valor máximo de una lista.
- `open()` abre un archivo en el modo que indiques.

Antes de escribir una función propia, revisa si ya existe. La documentación oficial en `docs.python.org` lo aclara para cada versión.

## Listas e índices

Una **lista** es la forma más común de implementar un array en Python: una secuencia ordenada de valores que puedes recorrer, modificar y consultar. Cada elemento tiene un **índice** que indica su posición. Aquí viene el detalle que confunde a todos: Python empieza a contar desde cero. El primer elemento es `[0]`, el segundo `[1]`, el tercero `[2]`.

```python
numeros = [10, 20, 30, 40, 50]
print(numeros[3])  # imprime 40
```

Las listas son **iterables**: puedes recorrerlas elemento por elemento para buscar, filtrar o transformar datos.

## Programación orientada a objetos, en breve

Python sigue el modelo de **programación orientada a objetos** (OOP). La idea es modelar cosas del mundo real como objetos. Un <a class="term" href="/glosario#OBJETO">objeto</a> tiene **propiedades** (atributos que lo describen) y **métodos** (acciones que puede realizar). Piensa en un auto: sus propiedades son color, modelo, año; sus métodos son arrancar, frenar, estacionar.

Una **clase** es la plantilla que define qué propiedades y métodos comparten los objetos del mismo tipo. La clase `Auto` engloba a un BMW, un Mercedes y un Audi. Las clases pueden tener **subclases** que heredan sus características: el modelo BMW 320i es un objeto de una subclase que hereda los métodos de la clase `Auto`. Si no entiendes estos conceptos, el código Python te va a parecer opaco.

## Banner grabbing: tu primer script de reconocimiento

Un **banner** es el mensaje que un servicio muestra cuando alguien se conecta a él. Es como un cartel de presentación: "Soy OpenSSH 7.3 en Debian". La técnica de leer ese banner se llama **banner grabbing**, y te da información crucial sobre qué aplicación y versión corre en un puerto antes de atacar.

Aquí usamos el módulo `socket` para conectarnos al puerto 22 (SSH) de la máquina local:

```python
#!/usr/bin/python3
import socket

s = socket.socket()
s.connect(("127.0.0.1", 22))
answer = s.recv(1024)
print(answer)
s.close()
```

Paso a paso:

1. `import socket` trae el módulo de red.
2. `socket.socket()` crea un objeto de conexión nuevo.
3. `s.connect(("127.0.0.1", 22))` se conecta a localhost en el puerto 22. La IP `127.0.0.1` apunta a tu propia máquina.
4. `s.recv(1024)` lee hasta 1.024 bytes de la respuesta y los guarda en la variable `answer`.
5. `print(answer)` muestra el banner en pantalla.
6. `s.close()` cierra la conexión.

Resultado:

```
SSH-2.0-OpenSSH_7.3p1 Debian-1
```

Con eso sabes qué aplicación, versión y sistema operativo corre ahí. Sitios como Shodan.io hacen exactamente esto, pero escaneando casi toda la internet y catalogando los resultados para que cualquiera los busque.
