# Linux: tu casa y tu taller

Tu <a class="term" href="/glosario#SISTEMA_OPERATIVO">sistema operativo</a> es el suelo donde se paran todos tus programas. En ciberseguridad, ese suelo casi siempre es Linux.

Antes de instalar nada, entiende qué estás pisando. Un sistema operativo es el software que administra los recursos físicos de tu máquina: le reparte <a class="term" href="/glosario#CPU">CPU</a>, <a class="term" href="/glosario#RAM">RAM</a> y <a class="term" href="/glosario#DISCO">disco</a> a cada programa que se ejecuta. Es el administrador del edificio: asigna habitaciones (memoria), depósitos (almacenamiento) y turnos de trabajo (procesador) a cada inquilino (programa). Sin sistema operativo, cada programa tendría que hablar directamente con el hardware, y nada podría coexistir.

## Por qué los hackers eligen Linux

Linux da un control que Windows no permite. Hay cinco razones concretas.

**Es de código abierto.** El código fuente del sistema está disponible: puedes leerlo, modificarlo y adaptarlo. Si querés que algo funcione de una forma para la que no fue diseñado, podés cambiarlo desde la raíz.

**Es transparente.** En Linux ves cada componente en funcionamiento, como si tuvieras una lintorna sobre cada engranaje. Windows esconde su interior a propósito; Linux te lo muestra.

**Es granular.** Tenés control casi infinito, desde el detalle más chico hasta el nivel más macro, todo desde la línea de comandos.

**Las herramientas nacen acá.** Más del 90 % de las herramientas de hacking están escritas para Linux. Aunque algunas se portan a Windows (como Metasploit o nmap), no todas sus funciones sobreviven el viaje.

**El futuro es Linux/Unix.** Dos de cada tres servidores web del mundo corren Linux/Unix. Más del 80 % de los móviles también (Android es Linux; iOS es Unix). Los routers, switches y sistemas de virtualización como VMware y Citrix se apoyan en el kernel de Linux.

## De Unix a Kali: el camino de las distribuciones

Linus Torvalds creó Linux en 1991 como alternativa de código abierto a Unix. Al ser abierto, voluntarios de todo el mundo escriben el kernel (el núcleo que controla la CPU, la RAM y demás) y las utilidades. No hay una empresa única que dicte las reglas, y por eso existen muchas variantes.

Esas variantes se llaman <a class="term" href="/glosario#DISTRIBUCION">distribuciones</a>: comparten el mismo kernel, pero cada una elige sus utilidades, aplicaciones e interfaz gráfica. Algunas conocidas: Debian, Ubuntu, Red Hat, CentOS, Mint, Arch y SUSE. Piensa en una distribución como un mismo modelo de auto equipado distinto: el motor es el mismo, los accesorios cambian según para quién se arma.

<a class="term" href="/glosario#KALI_LINUX">Kali Linux</a> es una distribución construida sobre Debian, desarrollada por Offensive Security y pensada para pentesters y hackers. Viene con cientos de herramientas preinstaladas: te ahorra las horas de descargar e instalar cada una.

## Pentesting y espionaje: para qué se usa esto

El <a class="term" href="/glosario#ETHICAL_HACKING">ethical hacking</a> (hacking ético, o "sombrero blanco") es atacar un sistema con permiso para descubrir sus debilidades y reforzarlo. Tiene dos ramas grandes.

El <a class="term" href="/glosario#PENETRATION_TESTING">penetration testing</a> (pentest) es un hack legal y por encargo. Primero se hace una valoración de vulnerabilidades, que suele generar muchos falsos positivos (cosas marcadas como fallos que no lo son). El pentester intenta explotar esos puntos para confirmar cuáles son reales antes de que la organización invierta en arreglarlos.

La otra rama es militar y de espionaje: casi todas las naciones hoy hacen ciberoperaciones, y el hacker se vuelve pieza clave de la defensa.

## Tu laboratorio: la máquina virtual

No necesitas borrar tu sistema actual para aprender. Una <a class="term" href="/glosario#MAQUINA_VIRTUAL">máquina virtual</a> (VM) es un sistema completo corriendo dentro de otro. Así podés tener Windows o macOS como anfitrión y, dentro, Kali Linux corriendo aislado.

La opción gratuita más usada es VirtualBox. El flujo para preparar tu VM:

1. **Descarga Kali** desde `https://www.kali.org/`. Elige la versión de 64 bits si tu CPU es moderna; la de 32 bits si es antigua. Para móviles o Raspberry Pi existe la arquitectura ARM (o Kali NetHunter en teléfonos). Puedes bajar por HTTP o por torrent.
2. **Instala VirtualBox** desde `https://www.virtualbox.org/`.
3. **Crea la VM**: nómbrala (por ejemplo, "Kali"), tipo Linux, versión Debian (64-bit).
4. **Asigna RAM**: no uses más del 25 % de tu memoria física. Con 16 GB en tu máquina, dale 4 GB a la VM.
5. **Crea el disco virtual**: tipo VDI, asignado dinámicamente (solo ocupa lo que usa). Reserva entre 20 y 25 GB: ampliarlo después es difícil, así que conviene pecar de generoso.

Si Kali falla al arrancar dentro de la VM, lo habitual es que la virtualización esté desactivada en tu BIOS, o que un software competidor (como Hyper-V en Windows) esté bloqueándolo.

## Instalar Kali dentro de la VM

Arranca la VM y selecciona el archivo `.iso` de Kali como disco de arranque. Elige **Graphical Install** y avanza por el asistente:

- **Idioma, ubicación y teclado.**
- **Hostname**: puedes dejar "kali".
- **Contraseña de root**. En Linux, <a class="term" href="/glosario#ROOT">root</a> es el superusuario: el administrador todopoderoso que puede reconfigurar el sistema, crear usuarios y cambiar contraseñas. Muchas herramientas de hacking exigen ejecutarse como root. Aunque en una VM el riesgo es menor, elige una contraseña larga.
- **Particionado**: *Guided - use entire disk* → *All files in one partition* → *Finish partitioning and write changes*. En una VM el disco está vacío, así que la advertencia de "se borrará todo" no afecta tus datos reales.
- **Mirror de red**: puedes decir *No*.
- **GRUB (bootloader)**: el cargador de arranque te deja elegir qué sistema iniciar. Instálalo y, cuando pregunte cómo, elige *Enter device manually* y selecciona el disco (algo como `/dev/sda`). La opción automática suele colgarse en pantalla negra.

Al reiniciar verás líneas de código y, luego, la pantalla de login. Entra como `root` con tu contraseña. Bienvenido a tu casa.

## Vocabulario que vas a pisar todos los días

Antes de moverte, ten a mano estos términos:

- **<a class="term" href="/glosario#BINARIO">Binarios</a>**: archivos ejecutables, equivalentes a los `.exe` de Windows. Viven en `/usr/bin` o `/usr/sbin` (por ejemplo, `ls`, `cat`, `ps`).
- **<a class="term" href="/glosario#DIRECTORIO">Directorio</a>**: lo mismo que una carpeta. Organiza archivos en jerarquía.
- **Home**: cada usuario tiene su `/home`, donde se guardan sus archivos por defecto.
- **Sensibilidad a mayúsculas**: `Desktop`, `desktop` y `DeskTop` son tres cosas distintas. Si te dice "archivo no encontrado" y estás seguro de que existe, revisa las mayúsculas.
- **Script**: una serie de comandos corridos por un intérprete. Muchas herramientas de hacking son simplemente scripts.

## La shell: tu herramienta principal

Toda esta的生活 se controla desde la línea de comandos. La <a class="term" href="/glosario#SHELL">shell</a> es el entorno y el intérprete que ejecuta esos comandos; la más usada se llama **bash** (Bourne-again shell). La <a class="term" href="/glosario#TERMINAL">terminal</a> es la ventana desde donde le hablás a la shell. Con el tiempo, casi todo lo que hagas en Linux pasará por ahí.

En la próxima lección vas a dar tus primeros pasos reales en esa terminal: moverte por el sistema de archivos y entender cómo se organizan los directorios. Esa es la calle por donde vas a caminar todos los días.
